How to use this gallery ▸

A curated set of reusable prompt templates for technical work. Every prompt is broken into highlighted parts so you can see why each piece is there before you use it.

  1. Choose a template from the categories on the left, or search above.
  2. Hover or keyboard-focus any highlighted section to read what it does, why it helps, and when to drop it. On a phone, just tap it.
  3. Edit if you like with Edit before copying — tweak wording or trim parts you don't need.
  4. Add your context by replacing the bracketed section at the end of each prompt.
  5. Copy and paste into ChatGPT, Claude, Claude Code, Codex, or any other AI tool.

Tip: press Tab to move between sections and Esc to dismiss a tooltip. Copy buttons always copy clean plain text — never the tooltips or highlights.
